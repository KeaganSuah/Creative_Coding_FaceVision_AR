Keagan's Image Processing Application

Press Capture to take a photo and Uncapture to recapture
Press "D" to activate Face Detection function
Press "C" to activate Capture function
Press "V" to activate Uncapture function
Press "S" to activate Save Image function

User Image Overlay:
Click "Upload Image" to select an image file
After upload, press keys 1–5 to change overlay placement:
  1: Middle
  2: Top
  3: Bottom
  4: Left
  5: Right
